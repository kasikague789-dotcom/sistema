Filtro de Groserías

¿Cómo funciona?
Cuando un usuario intenta crear o editar un perfil con palabras ofensivas en el nombre o apellido, el sistema bloqueará el guardado y mostrará un mensaje de error con sugerencias de texto filtrado.

Gestiona las palabras que se bloquean en todo el sistema (nombres, correos, contraseñas, fechas, descripciones, observaciones, calendario y horarios).
